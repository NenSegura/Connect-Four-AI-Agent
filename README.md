# Connect-Four-AI-Agent
Problem solving AI Agent to learn optimal Connect Four strategies

Hi there! 
I created this AI Agent to play Connect Four. It uses Python to create a smooth game and a challenging opponent.
I also used the data analysis library, NumPy for the multidimensional array object to create the board.
The mathematical functions used to create this game are labeled in the code to provide some guidance on my thought process.
For the most part, the game consists of multiple functions to check each row, column and diagonal for two or more pieces
and make decisions on where to prioritize defense and offense.
